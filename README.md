# KM Talang Kelapa DC

Cek KM patok jalan tol & posisi Jalan Lintas (Lintas Tengah & Lintas Pantai Timur), Bakauheni – Palembang.
Cukup kirim/tempel koordinat, pakai GPS HP, atau kirim screenshot koordinat (OCR).

- Cadangan: https://spxkordinat.github.io/km-talang-kelapa-dc/
