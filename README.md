# KM Talang Kelapa DC

Cek KM patok jalan tol & posisi Jalan Lintas (Lintas Tengah & Lintas Pantai Timur), Bakauheni – Palembang.
Cukup kirim/tempel koordinat atau pakai GPS HP.

- Buka versi web: halaman `index.html` (GitHub Pages)
- Aplikasi Android: `KM-Talang-Kelapa-DC.apk`
